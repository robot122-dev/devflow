# DevFlow

Современный адаптивный лендинг, разработанный с использованием React и Vite.

## О проекте

DevFlow — учебный проект, созданный в рамках производственной практики. Цель проекта заключается в разработке современного одностраничного веб-приложения с использованием библиотеки React и современных подходов к фронтенд-разработке.

## Используемые технологии

- React
- Vite
- JavaScript (ES6+)
- HTML5
- CSS3
- Git
- GitHub

## Возможности

- Адаптивный интерфейс
- Компонентная архитектура
- Современный дизайн
- Кроссбраузерность
- Оптимизированная структура проекта

## Структура проекта

```text
src/
├── assets/
├── components/
├── styles/
├── App.jsx
└── main.jsx
```

## Установка и запуск

Клонирование репозитория:

```bash
git clone https://github.com/robot122-dev/devflow.git
cd devflow
```

Установка зависимостей:

```bash
npm install
```

Запуск проекта:

```bash
npm run dev
```

Сборка проекта:

```bash
npm run build
```
